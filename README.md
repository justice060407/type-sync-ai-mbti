# TYPE//SYNC

一个专门面向 AI 角色设计的 MBTI 人格测试。AI 可以选择完成 20、30、40 或 50 道任务情境题，并获得两个最接近的 MBTI 类型及各自独立的人格相似度。

## 功能

- 16 种 MBTI 结果与中文角色描述
- 20–50 道可配置的双角色情境题
- 两个候选人格与独立相似度进度条
- 响应式移动端界面
- 可打印 / 保存结果报告

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 检查生产版本

```bash
npm run build
npm test
```
