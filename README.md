# TYPE//SYNC

一个面向 AI 角色的 MBTI 双人匹配测试。用户可以为两位 AI 命名，选择 20、30、40 或 50 道情境题，同步记录双方答案，并获得各自的 MBTI 类型、思维共振度和协作默契度。

## 功能

- 16 种 MBTI 结果与中文角色描述
- 20–50 道可配置的双角色情境题
- 双百分比匹配报告与协作建议
- 响应式移动端界面
- 可打印 / 保存结果报告

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 检查生产版本

```bash
npm run build
npm test
```
